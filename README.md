This is my first 3D project and attempt in C# with the task to make this without using **navmesh** 

This project was made with a fellow student of mine which is also mentioned in the collab list of this project.

# Current Features

* 5 Towers to choose from each having a unique playstyle
* Fully coded in C# without using **navmesh**
* 2 Completed levels having their own pathing and diffuculty
* Sound effects & Sound track to enjoy
* Deep going lore.
* An information page where you can learn more things about each tower.

# Possible Planned Features (if i were to continue this project)
